## 👨‍💻 About Me

I'm a **Cloud Engineer** who works across AWS and Azure, CI/CD pipelines, containers and infrastructure as code. I spent time at **MoEngage** keeping a large-scale, cloud-hosted SaaS platform reliable for enterprise customers. That meant incident response, root cause analysis, deployment troubleshooting and monitoring under strict SLAs.

Alongside engineering I teach. I've mentored **6,000+ learners**, including students aged 6 to 20 in AI/ML, Python and robotics at **Moonpreneur**, and I'm the **founder of KATS Guru**.

I hold a B.Tech (Hons) in Computer Science Engineering (Full Stack Software Development) from **Lovely Professional University**.

- ☁️ Focus: cloud infrastructure, DevOps and platform reliability
- 🧰 Daily tools: AWS, Azure, Terraform, Docker, Kubernetes, CI/CD, Python
- 🎓 Mentoring and teaching: Python, machine learning, RAG and agentic AI
- 📍 Based in India
